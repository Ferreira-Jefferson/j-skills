# FASE 7 — Review Final

> **Propósito:** Verificação de completude. Confirma que tudo foi implementado, testado e documentado.

Ao concluir todas as tasks, gere `.claude/specs/[feature-name]/REVIEW-FINAL.md` contendo:

## O que deve constar

- **Status das Tasks** — Tabela task × status × testes × observações
- **Cobertura de Requisitos** — Cada RF/RNF marcado como implementado + testado
- **Cobertura de Testes** — Métricas reais (unit %, integration cases, E2E flows)
- **Dívidas técnicas** — Itens identificados durante implementação + quando resolver
- **Checklist de entrega** — RFs completos, RNFs no SLA, cobertura atingida, sem TODOs críticos

## Adaptação

- Use os dados REAIS da implementação — porcentagens observadas, não metas
- Dívidas técnicas devem ter severidade e proposta de resolução
- Se algum RF não foi implementado, explique o motivo (descartado, adiado, bloqueado)

Após gerar, avance automaticamente para a FASE 8 (START.md) sem pedir aprovação.
